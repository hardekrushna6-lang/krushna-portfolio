# Krushna Harde Portfolio

A responsive portfolio inspired by the uploaded reference video.

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive design, typography, animation
- `script.js` — smooth navigation and interactive hero card

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on Vercel
1. Create a GitHub repository.
2. Upload these three files.
3. Import the repository into Vercel.
4. Deploy — no build command is required.

## Customize
Replace the `KH` circle with your own photo if you want. Update project links in `index.html` where the project buttons currently use `#`.
